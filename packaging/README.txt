AURORA 極光播放器
=====================================

封面沉浸式的 Windows 桌面音樂播放器。支援 MP3 / FLAC / WAV / OGG，
並會實際量測輸出音質與藍牙傳輸模式。


安裝
-----------------------------------

1. 把這個壓縮檔「完整」解壓縮到任意資料夾
   （直接在壓縮檔裡執行會失敗，因為程式需要旁邊的 _internal 資料夾）

2. 雙擊「安裝.bat」

就這樣。不需要 Python、不需要 Qt、不需要 VC++ 可轉散發套件，
全部都已經包在裡面。安裝過程不需要系統管理員權限。

程式會裝到：
    %LOCALAPPDATA%\Programs\AURORA

設定與播放清單存在：
    %APPDATA%\Aurora


讓音樂檔預設用 AURORA 開啟
-----------------------------------

安裝時已經把 AURORA 加進「開啟方式」清單。要設成預設：

    在音樂檔上按右鍵 → 開啟方式 → 選擇其他應用程式
    → 選「AURORA 極光播放器」→ 按「一律」

Windows 10 之後不允許程式自行把自己設成預設播放器，這是系統刻意的
防護設計，任何程式都繞不過去（宣稱做得到的都會被系統重設）。
所以最後這一步必須由你確認。


解除安裝
-----------------------------------

設定 → 應用程式 → 已安裝的應用程式 → AURORA 極光播放器 → 解除安裝

或直接執行安裝目錄裡的 uninstall.ps1。

預設會保留你的設定與播放清單。要一併清除：
    powershell -ExecutionPolicy Bypass -File uninstall.ps1 -Purge


系統需求
-----------------------------------

  Windows 10 1809 以上或 Windows 11
  64 位元（x64）；32 位元不支援
  約 200 MB 磁碟空間


快捷鍵
-----------------------------------

  空白鍵      播放 / 暫停
  ← →         倒退 / 快轉 5 秒
  Ctrl+← →    上一首 / 下一首
  ↑ ↓         音量
  M           靜音
  P           播放清單
  L           歌詞
  I           音質資訊
  Ctrl+L      音樂庫
  Ctrl+O      加入資料夾
  Ctrl+,      設定
  Ctrl+M      迷你模式
  C           電影模式
  F11         全螢幕
  Esc         退出目前模式
